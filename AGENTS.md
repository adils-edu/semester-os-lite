
# AI Development Instructions

Project: Semester OS Lite
Course: PED 379 — Web Programming

## Technology Rules
- Use semantic HTML5.
- Use external CSS3.
- Use vanilla ES6+ JavaScript.
- Do not introduce React, Tailwind, Bootstrap,
  or jQuery.
- Keep code modular and understandable.

## Development Rules
- Explain proposed code changes.
- Prefer small, incremental changes.
- Do not overwrite unrelated code.
- Preserve existing working functionality.
- Validate inputs and handle errors.
- Do not expose API secrets.
- Do not fabricate testing or contributions.

## Documentation
- Keep README.md updated.
- Document material AI contributions.
- Ensure every team member can explain the code.
